** Method
- Data :: for each task, have \(F*, M*, U*\), or files, modules, and functions. Took from prior similar work like swe bench variants.
- OpenHands-Bash :: unix commands like rg (ripgrep), find, ls, grep, sed.
- Reward :: F1 score on files, modules, and functions, then an turn reward if the agents terminates in k turns, k = step limit, to make sure it finishes within limit.
