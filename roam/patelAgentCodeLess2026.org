#+title: Is Agent Code Less Maintainable Than Human Code? - Patel, Shaswat and Hou, Betty Li and Purohit, Arun and Xu, Kai and Pan, Jane and He, He and Chen, Valerie

* CodeFlow
Topic of whether code generate slop (hard to maintain code)

- **PR 0**: function changed removed
- **PR 1**: function implemented with LLM
- **RP 2**: function edited by LLM

Then compare LLM function vs human function edit success rate

** Cause of the drift
Use logical regression to predict human only wins or machine only wins (on the subset where the outcome is different) and see their coefficient
- logical line of code on PR2, or over editing
- input/error contract: differences in exception types or swapped defaults in re-implementation
- difficult of the task, based on the success of the other 3 models on the same instance. On easier tasks HA wins.
